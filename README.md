# lootify

## Selenium Project to claim monthly reward for Dragonrealms subscribers
This project executes completely within a GitHub Action, in conjunction with the `selenium/standalone-chrome` docker image, to create an automated headless run.  You can execute the Python script locally if you wish, just set up your own Selenium environment.

## Ported from Kevin Kassner
This project was ported from Kevin's work in GitLab, which can found here: https://gitlab.com/desertkaz/lootcoins.  
It's largely the same, the workflow file has just been rewritten to work for GitHub.
